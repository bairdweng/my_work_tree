# 标题钩子库（xhs-luxury）

从高赞样本提炼。**样本原版多为素人买家口吻，只拆结构和落点，不抄人设、经历、情绪和价格。** 每条候选先过合规边界，再套转化写法。

## 一、可用钩子类型

### 1. 看点前置
- **定义**：第一句抛本篇最抓眼的一处（材质分区 / 结构亮点 / 配色），不先报品类参数。
- 样本原版：`Chanel 26高级手工坊新包，先背为敬`
- 商家号转化：`米色毛绒靴，先看这双卷毛鞋头款`
- 边界：看点必须实拍可见；不写"先背为敬"这类买家动作炫耀。

### 2. 材质 / 款式对比
- **定义**：用两种可验证材质或款型的差异做落点。
- 样本原版：`长毛筒和卷毛鞋头怎么分`
- 商家号转化：`长毛筒配卷毛鞋头，细节在这双上`
- 边界：对比双方都要在图里看得出来；不写"显脚小 / 显腿长"这类无实拍支撑的效果对比。

### 3. 数字细节
- **定义**：用可数的细节数量降低理解成本。
- 样本原版：`3 处细节`
- 商家号转化：`通勤毛绒靴 3 处细节｜卷毛鞋头系带毛球`
- 边界：数字对应真实可见的细节，不凑数。

### 4. 选择悬念
- **定义**：点出买家常见的选择纠结，本篇给方向。
- 样本原版：`纠结了半小时黑色还是白色`
- 商家号转化：`秋冬毛绒靴纠结配色？米白拼浅驼先看这双`
- 边界：只讲配色 / 款型选择，不编自己纠结的过程；不做"选哪个都不亏"的承诺。

### 5. 反差真香（受限使用）
- **定义**：先抑后扬，讲实物观感和预期的落差。
- 样本原版：`一开始觉得看不懂，几个月后真香了`
- 商家号转化：仅可讲**实物观感层面**的反差（如"图片看着普通，实物绒面更蓬松"），且须有实拍支撑。
- 边界：不编心路历程；没实拍不写"上脚真香 / 上身惊艳"；不贬低其他款。

### 6. 合集盘点
- **定义**：多篇 / 多款合集，用盘点感拉点击。
- 样本原版：`秋冬女鞋挑花眼`、`上脚合集`
- 商家号转化：`这季毛绒靴合集｜米白 / 浅驼几款先看`
- 边界：合集内每款都要有实拍；混款参考图不进发布序列。

### 7. 拥有感转化（去情绪）
- **定义**：样本用"拥有…的快乐"表达满足感；商家号只保留款型和看点，去掉买家情绪。
- 样本原版：`拥有 Chanel 26p 大号 hobo 的快乐`
- 商家号转化：`大号 hobo 包｜可调肩带慵懒款`
- 边界：不写"快乐 / 本命 / 绝美"等情绪词；稀缺度须真实可讲。

### 8. 季节 / 材质氛围
- **定义**：用季节和材质氛围词切入。
- 样本原版：`冬天就是毛绒绒 + 麂皮`
- 商家号转化：`秋冬毛绒靴｜米白卷毛中筒款`
- 边界：氛围词点到为止，不堆砌形容词。

### 9. 推荐 / 测评落点
- **定义**：直接以推荐、测评、讲款为落点。
- 样本原版：`好鞋推荐｜Chanel 26新款德训鞋`、`这钱花得有点冤？`
- 商家号转化：`毛绒靴讲款｜卷毛鞋头和系带毛球细节`
- 边界：测评只讲可验证的优缺点；不写"值不值回票价"这类价格判断。

## 二、禁用钩子（样本里出现也不搬）

- **明星 / 网红同款**：如 `Jennie 同款`；未授权不蹭。
- **设计师 / 名人名义**：如直接挂设计师名字背书。
- **地点 walkin / 逛店经历**：如 `京都 walkin 买到`、`逛了两家店`；商家号不编购买场景。
- **价差诱导**：如 `比国内便宜六千多`；不写价格对比引导私下成交。
- **夸张情绪词**：本命、最爱、绝美、嗲到犯规、封神等。
- **emoji 堆砌**：标题不连续堆 emoji；最多一个点缀。
- **纯系列号裸奔**：只有批次号没有品类 / 看点，截断后看不懂卖什么。

## 三、标题自检

- [ ] 前 13 字说清"是什么 + 给谁 / 什么场景"
- [ ] 带一个明确落点（看点 / 对比 / 数字 / 悬念 / 搭配 / 合集），不是纯属性堆叠
- [ ] ≤20 字，留截断余量
- [ ] 搜索词（品类 / 款型 / 季节 / 风格）已埋入
- [ ] 无禁用钩子、无极限词、无导流词
- [ ] 品牌词仅在实拍在售且归属确认后出现
