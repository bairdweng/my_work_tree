# 小红书奢侈品标签词库（xhs-luxury）

标签只从本库取；库外新词先判断是否与本篇强相关，再补进对应分类。**品牌词仅用于实拍在售款式，未经营品牌不蹭。**

## 一、每篇配比（5–8 个）

| 层级 | 数量 | 作用 | 选取规则 |
|---|---|---|---|
| 大词 | 1 | 进大类流量池兜底 | 品类 / 穿搭大类，不堆多个 |
| 中词 | 2–3 | 垂类细分，主战场 | 品类细分 + 风格 / 场景 |
| 长尾词 | 2–3 | 精准触达 | 品牌 + 款型 + 场景 / 痛点 |

- 有实拍在售品牌时品牌词必带 1 个，品牌 + 品类组合优先；本篇无可写品牌则不带，不蹭未经营品牌。
- 说不出"为什么加它"的标签删掉；无关热门话题不蹭。
- 一篇内标签口径一致，不混堆不相关大类。

## 三、系列号 / 批次词（精准长尾，谨慎使用）

大牌按季度 / 工坊系列编号（样本中出现的形如 `25s / 26p / 26s / 26b / 26N`）。

- **只在实拍可辨认批次时标注**；图里读不出批次就不写，不臆测字母对应哪个季节 / 系列。
- 不把批次号当成品牌背书；归属未确认前不带品牌 + 批次组合词。
- 常见写法参考：`#Chanel26p`、`#香奈儿26s`、`#Chanel25S德训鞋`；字母与数字的官方含义以品牌当季资料为准，文案不自行解释。

## 七、属性词

黑色、白色、棕色、米色、奶油色、金色、银色、拼色、撞色

### 材质 / 工艺

### 季节 / 风格

## 八、痛点 / 选购词

## 九、泛流量词（内容真相关才加，不硬蹭）

## 十、禁忌标签（一律不用）

- 极限词：#最 #第一 #顶级 #全网最低 #绝版捡漏
- 导流词：#加微 #私信 #同款链接 #代购联系方式
- 灰产 / 侵权词：#高仿 #A货 #原单 #复刻 #渠道货 #海关罚没 #精仿
- 未授权背书：#正品保证 #支持验货 #官方授权 #专柜同款背书（无授权不用）
- 碰瓷词：未经营品牌、未合作明星 / 网红同款名义
- 医疗 / 功效词：鞋包品类不适用，不写功效承诺
