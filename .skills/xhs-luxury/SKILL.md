# xhs-luxury 小红书奢侈品图文

## 适用范围

固定域：**小红书奢侈品 / 轻奢鞋履、包袋、配饰**图文笔记（彩妆不进本 skill）。账号为**普通商家号**（不走蒲公英），文案**纯中文**，鞋、包、配饰共用一套模板。

文章目录：`data/xhs/luxury/<文章-slug>/`，目录名英文小写加连字符；文案与物料随文存放。

## 合规底线（先于一切文案）

账号主体是商家，内容用**商家 / 从业者视角**（选品、材质、尺码、搭配讲解），不扮成普通消费者。以下任一命中即不交付：

1. **不伪装素人**：不写"自用半年、闺蜜问爆、被追着要链接"这类虚构买家口吻；不盗用他人素材冒充实拍。
2. **不隐瞒经营身份**：不用"求助、求推荐、有没有人知道"的口吻推自家货；不把商家内容包装成消费者自发分享。
3. **不编造人设与体验**：财富、学历、收入、情感经历、身高体重穿搭效果都不编；没真实上脚 / 上身就不写对应感受。
4. **不夸大、不伪造背书**：不写无法兑现的效果承诺；未经授权不借明星、机构、品牌名义虚构推荐。
5. **不站外导流**：笔记内不留微信、电话、外链、二维码，不写价格诱导私下成交。
6. **不碰灰产与侵权词**：高仿、A 货、原单、渠道货、海关罚没、复刻等一律不写；未获授权不写"正品保证、支持验货、官方授权、专柜同款背书"。
7. **品牌词只对应实拍在售款**：没经营、没实拍的品牌不蹭；AI 生成或辅助的图按平台要求标明。
8. **极限词禁用**：最、第一、顶级、全网最低、绝版捡漏等。

## 流程

### 1. 看图，先报"看到 / 看不到"

拿到图片先输出两段，不直接写标题：

- **能确定的**：品牌可见标识、品类、款型观感、材质分区、配色、角度、成色。
- **必须补的**：尺码 / 尺寸、成色、是否在售、实拍还是素材图、有无水印 / 中文标签 / 他人 logo。

图片看不出的参数、成色、上身效果，不臆测。

### 2. 固定确认项

每次先确认，缺项就停在原地：

1. 品类：鞋 / 包 / 配饰，具体细分款型。
2. 品牌与款型（对应实拍在售款，不碰瓷未经营品牌）。
3. 关键参数：尺码 / 尺寸、材质、配色、成色。
4. 本篇主打角度：材质讲解 / 穿搭搭配 / 尺码选购 / 合集 / 开箱。
5. 图片素材：现有几张、哪些待补。

### 3. 标题工作流

**字数**：标题前 13 字必须说清"是什么 + 给谁看 / 什么场景"，信息流截断后仍成立；整体控制在 20 字内为宜。

**钩子类型**：从 `references/hooks.md` 选，每条标题必须带一个明确落点（看点 / 对比 / 数字 / 悬念 / 搭配 / 合集），不允许纯属性堆叠。钩子先过合规边界，素人经历、明星、价差、夸张情绪一律不进标题。

**搜索词**：标题里埋品类、款型、季节、风格、场景等可验证搜索词；品牌词仅在实拍在售且归属确认后才带。

**输出**：3–5 条候选，标注钩子类型，人选定稿；不堆同义词、不堆砌 emoji、不写极限词与导流词。

### 4. 正文写法（高赞结构，商家视角转化）

**文件分两层**：`post.md` 顶部放「复制发布版」代码块（纯文本、不带 markdown 符号，整段可直接粘贴进小红书）；底部留档区存标题候选、卖点、物料清单、合规自检，仅供复盘，不发布。

**核心写法（区别于说明书罗列）**：

- **开头先抛看点**：第一句抛本篇最抓眼的点（材质分区 / 结构亮点 / 配色），不先报品类参数、不编故事。
- **按记忆点组织段落**：一段一个判断，材质与结构合并讲；**不按"版型 / 材质 / 配色"教科书类目切块**，不写长段落墙。
- **带可验证的取舍观感**：可以讲"两种绒面比通体一种更有层次"这类基于实拍的对比；不堆形容词，不写没实拍支撑的效果。
- **短句口语**：一句一行，段间空行，透气；书面词换口语，像从业者当面讲款。
- **实用细节夹在判断里讲**：尺码偏差、打理难度、可调结构、稀缺度等，素材能支撑才写；素材不支持就留白，不硬凑，不单列一段堆参数。
- **不编自用经历**：不写逛店、SA、闺蜜、家人出资、地点 walkin、价差对比。

**骨架 A · 单品型**（按记忆点顺序，非教科书类目）：

1. **开头看点**：一句话点出本篇最抓眼的一处。
2. **核心记忆点**：最有辨识度的一处先讲（绒面分区 / 包型轮廓 / 五金标识等）。
3. **结构与细节**：靴筒 / 包身、系带 / 肩带、标识、包边等可验证观感。
4. **配色**：主辅色、整体色调观感。
5. **搭配方向**：给具体可脑补的穿法方向；不写未上脚 / 上身验证的效果。
6. **选购提示（可选）**：尺码、适配、收纳提醒；素材不全或本篇不需要时整段删。
7. **结尾互动（可选）**：引导评论提问，不导流私域。

**骨架 B · 合集型**：

1. **开头定调**：本季 / 本篇整体看点，一句话。
2. **逐款点评**：每款一段，款型 + 取舍判断（主推 / 其次 / 常规 / 收藏向），可用 emoji 分段。
3. **收尾建议**：给整体选择方向，不替买家下结论。
4. 合集里每款都必须有实拍；混有其他款的参考合集图不进发布序列。

**语气规范**：

- 商家讲款的自然口语，禁说明书罗列腔（"靴筒为…鞋头为…"式排比压句）。
- 正文不写售后承诺、不写联系方式。

### 5. 话题标签

标签从 `references/tags.md` 取，按分层配比组合：

- 一篇 **5–8 个**，不堆满；配比 **1 大词 + 2–3 中词 + 2–3 长尾**；有实拍在售品牌时品牌词必带 1 个，本篇无可写品牌则不带，不蹭。
- 品牌词、品类词必带；场景 / 人群 / 属性 / 痛点按本篇内容选。
- 说不出"为什么加它"的标签删掉；无关热门词不蹭。

### 6. 配图槽位（6–8 张，3:4 竖版）

规格：1080×1440（或 1242×1656），一篇内比例统一；jpg/png，单张 ≤20MB；无水印、无他人 logo、无中文乱码标签。

| 槽 | 内容 | 作用 |
|---|---|---|
| 1 封面 | 上脚 / 上身或最抓眼整体图 | 决定点击 |
| 2 全景 | 正面 + 侧面 | 看版型轮廓 |
| 3 材质细节 | 皮料、车线、纹理 | 支撑质感 |
| 4 五金 / 标识 | 五金、Logo、标细节 | 认款 |
| 5 多角度 / 配色 | 换角度或配色对比 | 减少犹豫 |
| 6 尺寸参考 | 上脚比例、容量、尺码对照 | 减少纠纷 |
| 7 场景搭配 | 通勤 / 约会等穿搭场景 | 激发代入 |
| 8 包装 / 配件 | 盒、袋、配件（可展示才放） | 管理预期 |

少于 3 张信息单薄；第 8 张可砍。所有图统一放 `images/` 单目录，不另设原图目录；**默认不替用户修图**，只做导入和重命名，需要裁切、缩放、补角度等处理时先经用户明确授权。参考合集图用 `ref-` 前缀标注，不进发布序列。

### 7. 合规自检（发布前逐条过）

- [ ] 无素人伪装、无虚构自用经历
- [ ] 未隐瞒商家身份，无虚假求助 / 求推荐口吻
- [ ] 无人设编造（财富 / 学历 / 收入 / 情感 / 身高体重效果）
- [ ] 无盗图；AI 辅助已标明
- [ ] 无夸大功效、无未授权背书
- [ ] 无微信 / 电话 / 外链 / 二维码 / 私域导流
- [ ] 无极限词、无高仿 / A 货 / 原单 / 渠道货等灰产词
- [ ] 品牌词对应实拍在售款，未碰瓷未经营品牌
- [ ] 段落按记忆点组织，未套教科书类目切块；无未验证的上身 / 上脚效果
- [ ] 未擅自裁切、修饰、模糊、打码、AI 重绘用户素材；图片问题已在清单提示，未代为处理
- [ ] 标签均与本篇相关，无无关热门词

### 8. 回写 post.md

- 顶部「复制发布版」代码块始终保持纯文本可粘贴；底部留档区按节更新标题、卖点、标签、物料清单、合规自检、发布记录。
- 每次只改对应节，其余保持原样；留档口径与发布版一致，不出现两套说法。

## 硬性约束

- **不擅自改图**：用户发来的实拍 / 素材图原样使用，不裁切、不缩放、不旋转、不拼接、不调色、不模糊 / 打码、不去水印、不换背景，也不用 AI 重绘或生成缺失角度。图片问题（标签入镜、水印、比例、缺角度）只在物料清单里提示，由用户自行处理；用户明确授权后才可动图。
- 不编造图片看不出的参数、成色、材质、上身效果、授权关系。
- 不使用绝对化、医疗 / 功效类宣称。
- 不写未获授权的品牌背书与正品承诺。
- 不替用户决定最终是否发布；不代发笔记。
- 文案纯中文，不附英文对照。
