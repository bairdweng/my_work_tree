# eb-listing

## 适用范围

固定域：**RC 模型车配件**（轮胎、电机、电调、车壳、避震、配重、传动件等）。不必再确认品类归属，只需按零件类型选择属性组。

产品目录：`data/rc/eb/<产品名>/`，目录名用英文小写加连字符，与 SKU 一致。

## 流程

### 1. 看图，先报"看到 / 看不到"

拿到图片后，先输出两段，不要直接写标题：

- **能确定的**：比例、零件类型、胎纹/材质观感、是否含轮毂、颜色、大致适配车系。
- **必须补的**：尺寸、硬度、数量、兼容性、成本/售价。

### 2. 固定 5 问

每次都问这 5 项，其余按图片临时追加：

1. 规格尺寸（外径 / 宽度 / 内径，或对应零件的关键尺寸）
2. 材质或硬度（如 Soft / Medium / Hard，或 KV、T 数）
3. 包装数量（单条 / 4 条装 / 一对）
4. 兼容车系（SCX30、SCX24、TRX4M 等，明确写）
5. 成本或目标售价（用于后面出价格参考，不写进文案）

用户没答全就停在原地，不要用"通常""大概"去补。

### 3. 标题工作流（人机配合，七步）

**第 1 步｜备料（人）**：尺寸、材质、兼容车系、数量四项缺一即停，不往下走。颜色不进标题，放 Item Specifics。

**第 2 步｜词库（AI 拆，人删）**：拆 3–5 条竞品标题，输出词频表，分四类：品类词（Trailer / Tire / Motor）、属性词（Aluminum、CNC、1.0in、1/30）、场景词（Crawler、Off-Road）、数量词（4pcs、1pc）。人只需删掉不认可的表述。

**第 3 步｜排序（人定档）**：三档——必进、可进可出、不要。**没有真实搜索量数据时，只按相关性排序，不要假装有数据**；用户提供关键词工具截图才用搜索量。

**第 4 步｜组稿（AI）**：按 `品类词 + 兼容表述 + 属性 2–3 个 + 场景词 + 数量` 出 5–8 条候选。兼容一律写 `for X` 或 `Compatible with X`，不写 `Replacement for`、`Genuine`、`OEM`。

**第 5 步｜机器校验**：候选全部跑脚本，`✗` 改到全 `✓`，最多两轮。

```bash
python3 scripts/title_check.py "候选1" "候选2"
```

脚本检查：字符数 ≤80、无效词、权利风险词、颜色词、英式拼写（tyre/aluminium）、全大写、连续感叹号、是否以车型代号开头、含车型代号时有无 for/Compatible。**字符数一律以脚本输出为准，禁止目测。**

**第 6 步｜人工评审（人）**：只看三件事——读起来像不像人话；有没有不敢承诺的内容；前 40 字符能否说清这是什么。

**第 7 步｜定稿记录（AI）**：写入 `listing.md`，保留候选与被淘汰原因；发布后 14 天、30 天看曝光与点击再迭代，旧版本留档对照。

固定约束：
- 美国站拼写：`tire`、`aluminum`、`color`，不混用英式。
- 标题不写颜色，颜色交给 Item Specifics 与变体。
- 首词用品类词，车型代号只以 `for` 形式出现在兼容位置。
- 同一属性只说一次，不堆同义词；不加 emoji、全大写、`Best`、`Hot`。
- 不写未验证的兼容车型，不写任何暗示原厂或授权的表述。

### 4. 五点 + 描述 + Item Specifics

**五点**结构固定：选材工艺 / 即装即用 / 关键性能 / 结构细节 / 规格与包装。每条一句话，15 词以内。不写售后、不写运输。

**描述**用 Markdown 写在 `listing.md` 的 `## 描述` 小节，发布时由 `scripts/md2html.py` 转成 eBay 可用的安全 HTML。

描述固定五个区块：

1. Fitment —— 适配什么，**并明确写不适配什么**，这是减少纠纷的关键
2. Build —— 材质、工艺、结构
3. In the box —— 收到什么
4. Specs —— 尺寸、重量、材质，必须与 Item Specifics 一致
5. Why this one —— 使用场景，一句人话

长度：默认 ≤250 词，成套件且安装复杂的放到 450 词。不写运输、不写退换、不写保修承诺。不放外链、邮箱、电话、二维码。

写完必须跑：

```bash
python3 scripts/desc_check.py <listing.md>
python3 scripts/md2html.py <listing.md>
```

前者查长度、不可承诺表述、外链、联系方式、运输售后词、长段落；后者输出只含 `<p> <ul> <li> <strong> <br>` 的 HTML。不过就跑不交付。

**Item Specifics** 按零件类型取属性组：

| 零件 | 必填属性 |
|---|---|
| 轮胎 | Scale、Compatible Vehicle、Material、Quantity、Outer Diameter |
| 电机 | Scale、KV、Turns、Slots、Voltage |
| 车壳 | Scale、Compatible Vehicle、Body Style、Color |
| 电调 | Scale、Continuous Current、Voltage、Connector |
| 其他 | Scale、Compatible Vehicle、Part Type、Material、Quantity |

字段值只填已知的，未知留空并注明待补，不猜。描述里的规格数值必须与这里逐项对齐。

### 5. 图片标准（6 个固定槽位）

默认 6 张，每张必须回答一个买家问题，不做纯装饰图。少于此数转化吃亏，多于此数边际收益很低。

| 槽 | 文件名 | 作用 | 谁做 |
|---|---|---|---|
| 1 | `01-main.jpg` | 主图，搜索页缩略，决定点击 | AI 抠白底，人提供素材 |
| 2 | `02-compat.jpg` | 兼容证据：装车/接口咬合 | 人实拍，渲染图不可替代 |
| 3 | `03-size.jpg` | 尺寸与重量标注 | AI 叠标注，人给数据 |
| 4 | `04-detail.jpg` | 质感细节：材质纹理/轮组/胎纹 | AI 拼图，人提供特写 |
| 5 | `05-package.jpg` | 配件全家福，管理收货预期 | 人实拍 |
| 6 | `06-side.jpg` | 侧面/背面，补主图盲区 | 可砍，预算紧时最后补 |

砍图顺序：先砍 6，再砍 5，前 4 张保留。

技术规格：1600x1600、1:1、jpg、纯白底、单张 <12MB、无水印无边框无中文标签无他人 logo。eBay 上限 24 张、最低 500x500，主图会出现在搜索结果。

命名规则（自动化依赖，必须遵守）：

- 两位序号 + 固定角色词，`01-main.jpg`、`02-compat.jpg`……
- 全小写、连字符、无空格、无中文
- 序号保证排序，`10` 不会排到 `2` 前
- 主图只能是 `01-main`，其余依次递延

槽位清单写在同目录的 `images/manifest.json`：

```json
{"slot":1,"role":"main","file":"01-main.jpg","status":"ready","alt":"..."}
```

`status` 只有 `ready` / `pending` 两种。自动化发布只取 `ready`，`pending` 必须拦下。`alt` 可复用于图片说明与外站 SEO。

供应商图带水印、中文标签、他人品牌 logo 的，标注需重拍或修掉。原图放 `images/_source/` 保留，不进入发布序列。

### 6. 价格（美国站 / 包邮 / SpeedPAK）

口径固定：美国站、包邮、橙联 SpeedPAK 直发。不计广告费、不计退货成本。利润率按**占售价的百分比**算，不按成本加价倍数。

四笔成本：货款（含国内运费）、SpeedPAK 物流、关税、$0.40 固定费。

费率三项：成交费 13.6%（汽配同档，基数含买家付的销售税）、跨国交易费 1.55%（中国注册地址 → Rest of World）、汇损 1%。

公式：

\[
P = \frac{C + S + D + 0.40}{1 - 0.136(1 + t) - 0.0155 - 0.01 - m}
\]

`speedpak` 计费取 `154.50 元/kg + 操作费`（≤100g 24、101–200g 25、201–450g 28、>450g 39），最低按 50g 计。

两个方向都要跑：

```bash
# A：成本 → 保底价、目标价、敏感度
python3 scripts/price_calc.py --cost 65 --weight 250 --declared 18 --duty 0.25 --margin 0.30
# B：售价 → 利润
python3 scripts/price_calc.py --cost 65 --weight 250 --declared 18 --duty 0.25 --margin 0.30 --price 39.99
```

输出保底价、目标价、六档价位敏感度。看敏感度不是为了挑一个数，是为了看**哪一段是纯亏区**。

定不下来时按这个顺序判断：目标价高于市场同类成交价 → 先压货款，再降利润率，最后才考虑换产品。不接受低于保底价的定价。

**硬约束**

- 关税率必须来自实际 HS Code 归类或报关行报价，禁止凭感觉填
- 不把低报申报价当作调价手段
- 费率变动（eBay 改价、SpeedPAK 调价）要重跑，不沿用旧数
- 定价结论只写"保底价 / 目标价 / 采用价 / 依据"，不写"建议卖 $x"这种拍脑袋结论

### 7. 回写 listing.md

把结果写进 `data/rc/eb/<产品>/listing.md`，按节更新：图片清单、标题、五点、Item Specifics、价格、发布记录。每次只改对应节，其余保持原样。图片清单按 6 个槽位列出，标注 `ready` / `pending` 与负责人（AI 处理 / 需实拍）。

## 输出要求

- eBay 文案用英文成品；同时附中文对照，方便核对。
- 中文说明与英文成品分开呈现，不要把中文混进标题。

## 硬性约束

- 不编造图片看不出的参数、材质、兼容性、认证。
- 不使用绝对化或医疗/安全类宣称。
- 不写未获授权的品牌名、车型商标。
- 不替用户决定最终售价，不替用户点击发布。
- 图片里出现他人店铺水印、联系方式时，提示处理，不直接使用。
